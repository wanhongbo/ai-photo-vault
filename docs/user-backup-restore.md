# LumaNox 备份与恢复用户指南

本文说明 LumaNox 的备份文件、恢复密码和修改 PIN 后的使用规则。LumaNox 的备份是本地加密文件，恢复时需要输入生成该备份时使用的 6 位 PIN。

## 先记住这 4 条规则

1. 修改 PIN 前生成的备份，需要用旧 PIN 恢复。
2. 修改 PIN 后生成的备份，需要用新 PIN 恢复。
3. 如果修改 PIN 后自动备份覆盖了 `backup.dat`，新的 `backup.dat` 需要用新 PIN 恢复。
4. 手动导出的历史 `.aivb` 文件不会被自动修改，仍然需要用它导出时的 PIN 恢复。

## 备份文件有什么区别

LumaNox 当前有两类常见备份文件：

| 文件类型 | 来源 | 是否会被自动覆盖 | 恢复时使用的 PIN |
| --- | --- | --- | --- |
| `backup.dat` | 自动备份 | 可能会被下一次自动备份覆盖 | 生成当前这个 `backup.dat` 时的 PIN |
| `.aivb` | 手动导出备份 | 不会被自动覆盖 | 导出该 `.aivb` 文件时的 PIN |

可以把每一个备份文件理解成一份独立的加密快照。修改 PIN 只影响之后新生成的备份，不会重新加密已经存在的历史备份文件。

## 修改 PIN 后怎么判断输入哪个 PIN

看备份文件是什么时候生成的，而不是看当前 App 正在使用哪个 PIN。

| 场景 | 恢复时应该输入 |
| --- | --- |
| 修改 PIN 前手动导出的 `.aivb` | 旧 PIN |
| 修改 PIN 后手动导出的 `.aivb` | 新 PIN |
| 修改 PIN 前生成的 `backup.dat`，之后还没有被新的自动备份覆盖 | 旧 PIN |
| 修改 PIN 后自动备份已经成功覆盖 `backup.dat` | 新 PIN |
| 忘记旧 PIN，但手里只有修改 PIN 前的备份 | 无法恢复该旧备份 |

## 推荐使用方式

修改 PIN 后，建议立即做一次新的备份：

1. 手动导出一个新的 `.aivb` 文件。
2. 确认自动备份位置里的 `backup.dat` 已经完成新一轮备份。
3. 保留历史备份前，确认自己还记得它对应的旧 PIN。
4. 可以按日期整理备份文件，例如 `LumaNox-2026-05-25.aivb`。不要把真实 PIN 写进文件名、备注或聊天记录里。

这样做的好处是：之后如果需要恢复，你可以优先使用修改 PIN 后生成的新备份，并输入当前的新 PIN。

## 恢复时为什么会提示输入备份密码

这个“备份密码”就是该备份生成时使用的 6 位 PIN。它用于解密备份文件内容。

如果输入当前 PIN 无法恢复，请检查该备份是否是在修改 PIN 之前生成的。旧备份需要旧 PIN，这是正常的安全设计。

## 常见问题

### 修改 PIN 会让旧备份失效吗

不会。旧备份文件仍然可以恢复，但必须输入旧备份生成时的旧 PIN。

### 能不能用新 PIN 恢复旧备份

不能。新 PIN 只能恢复修改 PIN 后新生成的备份。历史备份不会因为你修改了 App PIN 而自动改用新 PIN。

### 修改 PIN 后自动备份覆盖了 `backup.dat`，还能用旧 PIN 恢复这个文件吗

不能。如果 `backup.dat` 已经被修改 PIN 后的新自动备份覆盖，它就是新的备份文件，需要用新 PIN 恢复。

### 手动导出的 `.aivb` 会被自动备份覆盖吗

不会。`.aivb` 是你手动导出的独立备份文件。只要文件本身没有被你删除或替换，它的恢复 PIN 就保持为导出当时的 PIN。

### 忘记旧 PIN 后，旧备份还能找回吗

不能。LumaNox 不上传、不保存你的 PIN，也无法替你解密历史备份。请妥善保存 PIN，并在修改 PIN 后及时生成新备份。

## 隐私说明

LumaNox 的备份与恢复在本地完成。备份文件和 PIN 不会上传到 LumaNox 服务器。请把备份文件保存在你信任的位置，并避免把 PIN 和备份文件放在同一个不安全位置。
