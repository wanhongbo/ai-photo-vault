Backup and restore

After changing your PIN, which PIN restores a backup?

LumaNox backups are locally encrypted files. When restoring, enter the 6-digit PIN that was in use when that specific backup file was created, not simply the PIN currently used by the app.

Core rules

Backups created before a PIN change

Restore them with the old PIN.

Backups created after a PIN change

Restore them with the new PIN.

Automatic backup overwrote backup.dat

If the overwrite happened after the PIN change, the new backup.dat restores with the new PIN.

Older manually exported .aivb files

They are not changed automatically. Restore each file with the PIN used when that file was exported.

Two backup file types

File type Source Can it be overwritten automatically? PIN to enter when restoring
backup.dat Automatic backup Yes. A later automatic backup may replace it. The PIN used when the current backup.dat was created.
.aivb Manual export No. It is an independent file unless you delete or replace it yourself. The PIN used when that .aivb file was exported.

Think of each backup file as an independent encrypted snapshot. Changing your PIN affects backups created after the change. It does not re-encrypt backup files that already exist.

Scenario guide

Scenario Enter this PIN when restoring
A .aivb file manually exported before the PIN change Old PIN
A .aivb file manually exported after the PIN change New PIN
A backup.dat created before the PIN change and not yet overwritten by a newer automatic backup Old PIN
A backup.dat successfully overwritten by automatic backup after the PIN change New PIN
You forgot the old PIN and only have backups created before the PIN change That old backup cannot be restored.

Recommended steps

  1. After changing your PIN, export a new .aivb file manually.
  2. Confirm the automatic backup location has received a fresh backup.dat.
  3. Before keeping older backups, make sure you still remember the old PIN for those files.
  4. Name backup files by date, such as LumaNox-2026-05-25.aivb. Do not put your real PIN in filenames, notes, or chat messages.

FAQ

Does changing my PIN invalidate older backups?

No. Older backup files can still be restored, but they require the old PIN used when they were created.

Can I restore an old backup with my new PIN?

No. Existing backups are not automatically changed to use the new PIN.

If automatic backup overwrote backup.dat after I changed my PIN, can I still use the old PIN?

No. The overwritten backup.dat is a new backup file and should be restored with the new PIN.

Can automatic backup overwrite my manually exported .aivb files?

No. A .aivb file is an independent manual export. Its restore PIN stays tied to the moment it was exported.

Can LumaNox recover an old backup if I forget the old PIN?

No. LumaNox does not upload or store your PIN and cannot decrypt historical backups for you.

Privacy reminder

LumaNox backup and restore are handled locally. Backup files and PINs are not uploaded to LumaNox servers. Store backup files somewhere you trust, and avoid keeping the PIN and backup file together in an unsafe place.
